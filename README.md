# Seminar 書報討論

用於存放書報討論課程之作業繳交紀錄，包含課堂筆記與完整報告。

---

## 作業要求

### A. 上課筆記（四次演講）— 40%（10% × 4 次）

**繳交規定**
- 每次演講需繳交手寫課堂筆記（Handwritten Lecture Notes）
- 筆記須包含以下項目：
  - 日期（Date）
  - 講者（Speaker）
  - 題目（Title）
  - 筆記內容（Note Content）
- **繳交期限**：演講完當天繳交（Submit on the day of the lecture）

---

### B. 完整報告（兩篇）— 30%（30% × 2 次）

**繳交規定**

報告須包含以下項目：

1. 日期、講者、題目
2. 簡介（Introduction）
3. 相關技術說明（Related Technical Description）
4. 心得報告（Reflections / Personal Insights）
5. 關鍵字（Keywords）
6. 參考文獻（References）

- **繳交期限**：演講當週繳交（Submit within the week of the lecture）
